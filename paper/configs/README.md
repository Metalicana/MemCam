# Figure Inputs

These JSON files were moved from `paper/` without changing scientific values.
Paths inside configurations are relative to the repository root unless a
builder explicitly documents otherwise; moving a config does not change that
convention.

| File | Used For |
| --- | --- |
| `motivation_teaser_inputs.json` | Motivation layout, retrieval source, and sample choices |
| `revisit_drawio_selection.json` | Editable MemCam revisit figure and highlight boxes |
| `worldmem_revisit_selection.json` | Editable WorldMem revisit figure and highlight boxes |
| `revisit_comparison_selection.json` | Selected revisit comparisons |
| `rollout_comparison_selection.json` | Five-frame rollout comparisons |
| `retention_selection_180s_reported.json` | Reported 180-second diagnostic estimates |
| `vbench_radar_scores.json` | Saved inputs to the VBench radar plot |
| `worldmem_lookup_reported.json` | Reported WorldMem lookup-work summary |

Reported summaries are not substitutes for raw measurements. The files retain
their source and interpretation notes. Example selections are figure inputs,
not changes to evaluation cohorts.
