# Result Snapshots

Imported results are grouped here; no scores or cohort memberships were
changed during reorganization.

| Directory | Contents |
| --- | --- |
| [metric_results_60s/](metric_results_60s/) | `scores.csv`, coverage audit, and metric report |
| [retention_selection_60s_full_grid/](retention_selection_60s_full_grid/) | Query/trajectory summaries, gap analysis, and budget figures |

These directories previously lived directly under `paper/`. Their original
names and contents are retained. Manuscript imports and plotting defaults now
use `paper/results/...`.

Historical reports and provenance can still name the original local or Newton
paths. They record where an artifact was produced; those paths have not been
rewritten to imply that experiments were rerun. New exports record current
source locations. Large generation outputs remain outside the repository.
